# AI workspace

This directory contains compact, machine-friendly guidance for coding agents.

## Read order

1. `../AGENTS.md`
2. `project.json`
3. `../PROJECT.md` when behavior/product scope matters
4. the target module and its tests
5. the relevant ADR only when an architectural decision is involved

## Directories

- `tasks/`: prompt/task skeletons with acceptance criteria.
- `examples/`: canonical patterns to copy before inventing a new structure.
- `project.json`: compact stack and architectural constraints.

Do not treat examples as product code. They are references for shape and conventions.
